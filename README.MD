# Semester 3 Python Practice

This repository contains Python programs and Jupyter notebooks created for academic assignment and laboratory practice purposes. The exercises introduce fundamental Python programming concepts through simple, practical examples.

## Topics Covered

- Loops and nested loops
- Fibonacci sequences and multiplication tables
- Star-pattern printing
- Lists, tuples, and sets
- Dictionaries and character frequency
- Sorting and basic data processing
- User input and exception handling
- Menu-driven banking transaction simulation

## Requirements

- Python 3.10 or later
- Jupyter Notebook or JupyterLab for notebook files

No third-party Python packages are required.

## Usage

Run a Python program from the repository folder:

```bash
python "29-08-2026/fibonacci.py"
```

Run the banking simulator with:

```bash
python "lab test.py"
```

To open the notebooks, start Jupyter Notebook or JupyterLab and select the required `.ipynb` file.

## Notes

These programs are standalone educational exercises and are intended to demonstrate basic Python syntax, data structures, algorithms, and input handling.
